# Sales Fraud Monitoring Airflow
 
 ## About
This project is a fraud monitoring pipeline built with Apache Airflow, 
Python and PostgreSQL. The main goal is to orchestrate an automated ETL 
pipeline that extracts, transforms and loads financial transaction data, 
identifying suspicious patterns.

## Technologies
- Apache Airflow 3.2.2
- Python 3.12
- Pandas
- PostgreSQL
- SQL

## Pipeline Architecture
Extract → Transform → Load

## Data Source
Sample of the Kaggle Credit Card Fraud Detection dataset 
(10,000 transactions subset for local development).
Original dataset: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
